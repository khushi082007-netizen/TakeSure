How to add your voice (Clipchamp, about 20 minutes)

  1. Open Clipchamp (it is on Windows 11) → Create a new video → drag TakeSure_Demo_ScreenRecording.mp4 onto the timeline.
  2. Left bar → Record & create → Audio. Play from the start and record while reading the lines above as each part appears.
  3. If you stumble, stop and re-record just that part; drag each clip so it starts at the time in the table.
  4. Export → 1080p → save as TakeSure_Demo_Voice.mp4. Upload that one.
Prefer to record it yourself from scratch? Press Win + Alt + R (Xbox Game Bar) with the site open in Chrome at http://localhost:3000, follow the same click path as the table (home → Check safety → Type the names → Match → Confirm → scroll the result → हिन्दी → Dashboard → Evidence curation → mismatch → Details → Knowledge base → Report a reaction), and talk while you click. Press Win + Alt + R again to stop; the file is in Videos\Captures. Either video is fine for the submission.
